# CV en ligne — Diallo Mamadou

> Portfolio digital haute-fidélité, cinématographique — Professeur de Lycée en Physique-Chimie, Côte d'Ivoire.

## ✨ Stack

- **React 18** + **Vite 5**
- **GSAP 3** + **ScrollTrigger** — animations au scroll
- **Lucide React** — icônes
- **Tailwind CSS** — utilitaires
- **Google Fonts** — Plus Jakarta Sans, Cormorant Garamond, IBM Plex Mono

## 🚀 Lancer en local

```bash
npm install
npm run dev
```

## 🏗️ Build production

```bash
npm run build
npm run preview
```

## 📁 Structure

```
cv-diallo-mamadou/
```

## 🎨 Design — Preset A "Architecte Minimal"

- Palette : Corail `#E8634A` sur fond Ivoire `#FAFAFA` / Charbon `#1C1C1E`
- Typographie triplette : Sans-serif (Jakarta) · Serif italique (Cormorant) · Monospace (IBM Plex)
- Sections : Hero · À propos · Expériences (timeline) · Compétences (circles SVG) · Formation · Contact
